# Project front ucua digital page
### made in react js
### run with npm start -o

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/your-repo/tienda_front.git
    ```
2. Navigate to the project directory:
    ```bash
    cd tienda_front/BotWhatsapp
    ```
3. Install dependencies:
    ```bash
    npm install
    ```

## Usage

1. Start the development server:
    ```bash
    npm start -o
    ```
2. Open your browser to view the application.

## Features

- Built with React.js for a dynamic user interface.
- Easy to set up and run locally.
